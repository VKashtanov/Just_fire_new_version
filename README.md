## Микросервис для сервиса "Просто огонь"

### Общее
Разработанный на Spring Boot микросервис «Просто огонь» контейнеризирован с помощью Docker и оркестрируется 
в Kubernetes, при этом виджет платформы Incomand обращается к нему напрямую, также для дополнительного разделения
слоёв и снижения связанности возможно внедрение легковесного адаптера / шлюза (преобразователя). Также был разработан служебный модуль
OSGi который служит только для служебных вызовов . Такой подход позволяет жёстко отделить бизнес-логику от 
портальной части, повысить стабильность и отказоустойчивость, снизить потребление памяти (уйти от 
необходимости в 4+ ГБ на ноду Incomand), обеспечить горизонтальное автоматическое масштабирование, 
полную независимость от технологии фронтенда и возможность наращивать observability (логи, метрики, трейсинг) 
без какой-либо нагрузки на ядро Incomand, что в итоге кратно повышает производительность и надёжность всей 
системы.

### Коммерческий потенциал:

Благодаря тому, что основная бизнес-логика вынесена в независимый Spring Boot микросервис, данное решение может быть использовано
для коммерциализации как самостоятельный продукт. Микросервис может работать поверх любого фронтенда — не только Incomand, но и других порталов, веб-приложений или мобильных клиентов. При этом единственной точкой интеграции с Incomand остаётся легковесный OSGi-модуль, который при необходимости легко заменить на другой адаптер. Это делает продукт готовым к тиражированию, лицензированию и внедрению у сторонних заказчиков без привязки к конкретной платформе.

### Преимущества для DevOps:

Поддержка микросервиса не требует глубоких знаний Liferay/OSGi:
- быстро развернуть сервис в любой cloud-среде или on‑premise;
- легко масштабировать под нагрузку одной командой 
- централизованно собирать логи и метрики;
- выполнять обновления без остановки сервиса
- откатить версию при проблемах
